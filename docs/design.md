# MUSIC CUP 第一版

用户已确认的作品集项目：高级黑紫霓虹视觉、移动与桌面自适应、搜索歌手、真实曲目和封面、单列选歌、16/32/64 淘汰赛、拖动缩放、点击晋级、本地恢复、冠军分享导出。

架构：React 18 + Vite 静态应用；iTunes JSONP 无密钥跨域访问，按歌手 ID 查询歌曲及专辑并分批补全专辑曲目。保留 live 等版本差异，以规范化名称去重同版本重发。可选择地区，显示覆盖与部分失败。API 限流、地区版权会影响完整性，不声称全部作品。

界面：紫色唱片视觉、宽松标题、单列真实歌库、右侧 sticky 赛事面板；手机单列和底部操作。MIT @oliverlooney/react-brackets 负责赛树结构，react-zoom-pan-pinch 提供画布控制。所有轮次保留完整树，修改早期胜者自动清空受影响的后续分支，提供撤销。

数据：本地保存唯一当前赛事与选择，存储失败明确提示。分享 URL 仅含冠军名称/歌手/参赛数量，打开不覆盖现有赛事。可导出不含版权封面的原创冠军 PNG 与赛事 JSON，导入校验结构。

交付：公开 GitHub music-cup（权限可用时）、可验证部署，README 中提供运行、测试、部署步骤及第三方许可。外部授权不可用则如实报告。
